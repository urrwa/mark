# Mark Aurel × SnapSell Academy

German-language academy website built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```sh
cd snapsell-academy
npm ci
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

```sh
cd snapsell-academy
npm run build
```

The production output is generated in `snapsell-academy/dist`.
